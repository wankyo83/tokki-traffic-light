# 토끼 신호등

웹툰·만화 확장앱 사이트의 접속 상태와 사용 가능한 최신 번호 주소를 간단히 보여주는 GitHub Pages입니다.

- 기본 주소가 실패하면 도메인 번호를 `+10`까지 순서대로 검사합니다.
- 정상 주소를 발견하면 사이트 고유 문구와 웹툰·만화 콘텐츠 구조까지 검증한 뒤 표시합니다.
- 모든 후보가 실패하면 마지막 오류 사유를 표시합니다.
- GitHub Actions가 10분 간격으로 검사를 시작하고, 같은 도메인의 서비스는 20초 시간차를 두고 확인합니다.
- 검사 결과는 Git 커밋을 만들지 않고 GitHub Pages에 바로 배포합니다.
- 순간적인 DNS/연결 오류에는 마지막 정상 주소를 유지합니다.
- 새 번호 주소는 두 번 연속 확인된 뒤 확장앱용 최신 주소로 승격합니다.

확장앱은 `domains.json`에서 최신 주소만 읽고, 관리 페이지는 `status.json`에서 상세 검사 상태를 표시합니다.

검사 대상과 경로는 `checker/sites.json`에서 관리합니다.
