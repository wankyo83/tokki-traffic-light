# 토끼 신호등

웹툰·만화 확장앱이 사용하는 최신 주소를 한곳에서 확인하기 위한 GitHub Pages입니다.

- Newtoki·Toki·SBXH는 `뉴토끼우회.com`의 구버전·실시간·고정 주소 링크를 각각 사용합니다.
- WFWF는 [늑대닷컴 공식 텔레그램](https://t.me/s/wftoon)의 `늑대닷컴 주소` 항목만 사용하며 `늑대닷컴2 주소`는 제외합니다.
- Blacktoon은 `blacktoonurl.net`의 첫 번째 블랙툰 바로가기 링크를 사용합니다.
- Jjaptoon은 공식 텔레그램 공개 페이지에서 주소가 포함된 가장 최근 게시물을 사용합니다.
- 11toon과 Naver는 정해진 고정 주소의 접속 여부만 확인합니다.
- Goodtoon은 공식 텔레그램에서 숫자가 붙은 `goodtoonNNN.com` 주소만 사용하고 `goodtoon.top`은 제외합니다.
- Newxtoon은 `뉴엑스툰주소.com`이 안내한 최신 주소만 사용합니다.
- Linkkf는 공식 X 프로필에 안내된 주소 중 `linkkf.tv`를 우선 사용합니다.
- 애니24는 공식 텔레그램의 가장 최근 게시물에서 `.net` 주소만 사용합니다.
- 티비위키는 공식 텔레그램의 `티비위키 우회 주소`로 안내된 `tvwiki.store`를 주소 탐지 출처로 사용합니다. 관문 응답이 직접 알려주는 `tvwiki숫자.net` 목적지를 검증한 뒤 그 HTTPS 주소만 확장앱용 최신 주소로 공개합니다.
- 애니라이프는 최신 주소 안내처를 찾을 때까지 현재 주소 `anilife01.tv`를 수동 고정 등록합니다.
- 실제 작품 사이트에는 접속하지 않으며 주소 참조처만 확인합니다. 참조처 확인 실패 시 원인을 표시하고 마지막 확인 주소를 유지합니다.
- 숫자 주소를 `+10` 방식으로 추측하지 않으며, 안내된 주소 외의 후보를 탐색하지 않습니다.
- 새 주소는 두 번 연속 같은 값이 확인된 뒤 최신 주소로 승격합니다.
- 주소 출처 확인이 실패하면 마지막으로 확인된 주소를 유지합니다.
- GitHub Actions가 10분 간격으로 확인하고 Git 커밋 없이 GitHub Pages에 배포합니다.

확장앱용 주소는 `domains.json`, 관리 화면 상태는 `status.json`에서 제공합니다.

신뢰 주소 안내처가 사이트별 허용 도메인 형식 안에서 새 번호를 안내하면 즉시 확정 주소로 반영합니다. 도메인 이름이나 최상위 도메인이 달라진 후보는 자동 반영하지 않고 관리 화면에 `새 주소 확인 중`으로 표시해 직접 확인하도록 합니다.
